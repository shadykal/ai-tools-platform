# AI Tools Platform

منصة متكاملة لأدوات الذكاء الاصطناعي مبنية بـ **Next.js 16** + **TypeScript 5** + **Tailwind CSS 4** + **React 19**

[![Status](https://img.shields.io/badge/status-active-brightgreen)](https://github.com)
[![Version](https://img.shields.io/badge/version-1.0.0-blue)](https://github.com)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

---

## 🎯 نظرة عامة

منصة شاملة توفر مجموعة من أدوات الذكاء الاصطناعي لإنشاء محتوى احترافي:

| الأداة | الحالة | الوصف |
|-------|---------|--------|
| **🎬 السيناريو والقصة** | ✅ جاهزة | توليد سيناريوهات واقعية مع شخصيات ومشاهد |
| **🎨 نص إلى صورة** | 🔄 تحت التطوير | توليد صور من الأوصاف النصية |
| **🎥 فيديو إلى فيديو** | 🔄 تحت التطوير | تحسين وتحويل الفيديوهات |
| **📽️ صورة إلى فيديو** | 🔄 تحت التطوير | تحويل الصور الثابتة لفيديوهات ديناميكية |
| **🎬 نص إلى فيديو** | 🔄 تحت التطوير | إنشاء فيديوهات من النصوص |
| **🎙️ توليد الصوت** | 🔄 تحت التطوير | توليد أصوات طبيعية من النصوص |

---

## ⚡ البدء السريع

### المتطلبات:
- **Node.js:** 18 أو أعلى
- **npm:** 9 أو أعلى

### التثبيت والتشغيل:

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل السيرفر التطويري
npm run dev
```

### الوصول للمنصة:
```
http://localhost:3000                      # الصفحة الرئيسية
http://localhost:3000/tools/storyboard    # أداة السيناريو
```

## ✅ الميزات المكتملة

### أداة السيناريو والقصة (Storyboard) ✨

**الميزات:**
- ✅ توليد فوري للسيناريوهات
- ✅ 5 أنواع من السيناريوهات
- ✅ شخصيات متكاملة مع صفات واقعية
- ✅ مشاهد مترابطة وذات معنى
- ✅ حوارات ديناميكية احترافية
- ✅ تصدير (Markdown, JSON)
- ✅ دعم المعربة الكاملة

**الأنواع:**
- دراما رومانسية
- أكشن
- كوميديا
- رعب
- خيال علمي

**الاستخدام:**
```
POST /api/tools/storyboard
{
  "title": "اسم السيناريو",
  "genre": "دراما رومانسية",
  "sceneCount": 5,
  "characterCount": 3
}
```

📖 [اقرأ الدليل الكامل](./STORYBOARD_GUIDE.md)
